# Agent Rules

This folder is gitignored, with specific checked in files exempted. Developers
are encouraged to put their personal Chromium-specific rules in this same
folder.

Checked in rules should be applicable to all developers in almost all
scenarios.

See https://antigravity.google/docs/rules-workflows for an explanation of
rules.
